# Usando ENS

## Original (English)

# Using ENS

Once you have registered an ENS name, you can use it in various ways:

## Setting Records

### Ethereum Address
The most common use case is to set your Ethereum address as the primary record for your ENS name. This allows others to send you ETH or interact with your smart contracts using your human-readable name instead of your long hexadecimal address.

### Other Cryptocurrency Addresses
You can also set addresses for other cryptocurrencies:
- Bitcoin (BTC)
- Litecoin (LTC)
- Dogecoin (DOGE)
- And many more

### Content Hash
You can set a content hash to point your ENS name to a website or IPFS content.

### Text Records
You can store various text records such as:
- Email address
- URL
- Avatar
- Description
- Keywords
- And custom records

## Resolving Names

### In Wallets
Most Ethereum wallets support ENS names. You can:
- Send ETH to `alice.eth` instead of `0x1234...`
- Use ENS names in DeFi applications
- Display ENS names instead of addresses

### In Applications
Many dApps support ENS names:
- DeFi protocols
- NFT marketplaces
- Social platforms
- And more

## Subdomains

If you own a domain, you can create subdomains:
- `pay.alice.eth`
- `mail.alice.eth`
- `nft.alice.eth`

You can delegate control of subdomains to other addresses or smart contracts.

## Traducción (Español)

# Usando ENS

Una vez que hayas registrado un nombre ENS, puedes usarlo de varias maneras:

## Establecer Registros

### Dirección de Ethereum
El caso de uso más común es establecer tu dirección de Ethereum como el registro principal para tu nombre ENS. Esto permite que otros te envíen ETH o interactúen con tus contratos inteligentes usando tu nombre legible por humanos en lugar de tu larga dirección hexadecimal.

### Otras Direcciones de Criptomonedas
También puedes establecer direcciones para otras criptomonedas:
- Bitcoin (BTC)
- Litecoin (LTC)
- Dogecoin (DOGE)
- Y muchas más

### Hash de Contenido
Puedes establecer un hash de contenido para que tu nombre ENS apunte a un sitio web o contenido IPFS.

### Registros de Texto
Puedes almacenar varios registros de texto como:
- Dirección de correo electrónico
- URL
- Avatar
- Descripción
- Palabras clave
- Y registros personalizados

## Resolver Nombres

### En Wallets
La mayoría de wallets de Ethereum soportan nombres ENS. Puedes:
- Enviar ETH a `alice.eth` en lugar de `0x1234...`
- Usar nombres ENS en aplicaciones DeFi
- Mostrar nombres ENS en lugar de direcciones

### En Aplicaciones
Muchas dApps soportan nombres ENS:
- Protocolos DeFi
- Mercados de NFT
- Plataformas sociales
- Y más

## Subdominios

Si posees un dominio, puedes crear subdominios:
- `pay.alice.eth`
- `mail.alice.eth`
- `nft.alice.eth`

Puedes delegar el control de subdominios a otras direcciones o contratos inteligentes.
