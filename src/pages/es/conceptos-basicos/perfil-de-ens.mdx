# Perfil de ENS

## Original (English)

# ENS Profile

An ENS profile is a collection of records associated with an ENS name that together form a complete digital identity. This includes various types of information that can be displayed in applications and used for different purposes.

## Profile Components

### Basic Information
- **Name**: The ENS name (e.g., `alice.eth`)
- **Avatar**: Profile picture or image
- **Description**: Brief description or bio
- **URL**: Personal website or social media link

### Contact Information
- **Email**: Contact email address
- **Twitter**: Twitter handle
- **GitHub**: GitHub username
- **Discord**: Discord username

### Cryptocurrency Addresses
- **ETH**: Ethereum address
- **BTC**: Bitcoin address
- **LTC**: Litecoin address
- **DOGE**: Dogecoin address
- And many more supported cryptocurrencies

### Custom Records
You can add custom text records for any purpose:
- **Keywords**: Tags or keywords
- **Location**: Geographic location
- **Timezone**: Time zone information
- **Language**: Preferred language
- **Custom fields**: Any other information you want to store

## Setting Up Your Profile

### Step 1: Register Your Name
First, you need to register an ENS name through the ENS Manager.

### Step 2: Add Records
1. Go to your name in the ENS Manager
2. Click "Add/Edit Record"
3. Select the record type you want to add
4. Enter the information
5. Save the record

### Step 3: Set Primary Name
If you want this to be your primary ENS name:
1. Go to your address in the ENS Manager
2. Click "Set Primary Name"
3. Select your ENS name

## Displaying Profiles

### In Wallets
Many wallets can display ENS profiles:
- Show avatar and name instead of address
- Display additional profile information
- Link to profile details

### In Applications
dApps can use ENS profiles for:
- User identification
- Social features
- Contact information
- Custom data display

## Best Practices

### Keep Information Updated
- Regularly update your profile information
- Remove outdated records
- Add new relevant information

### Privacy Considerations
- Only add information you're comfortable sharing publicly
- Remember that ENS records are public on the blockchain
- Consider using different names for different purposes

### Profile Completeness
- Add an avatar for better recognition
- Include a description to help others understand who you are
- Add relevant social media links
- Include your primary cryptocurrency addresses

## Traducción (Español)

# Perfil de ENS

Un perfil de ENS es una colección de registros asociados con un nombre ENS que juntos forman una identidad digital completa. Esto incluye varios tipos de información que pueden mostrarse en aplicaciones y usarse para diferentes propósitos.

## Componentes del Perfil

### Información Básica
- **Nombre**: El nombre ENS (ej., `alice.eth`)
- **Avatar**: Foto de perfil o imagen
- **Descripción**: Breve descripción o biografía
- **URL**: Sitio web personal o enlace de redes sociales

### Información de Contacto
- **Email**: Dirección de correo electrónico de contacto
- **Twitter**: Handle de Twitter
- **GitHub**: Nombre de usuario de GitHub
- **Discord**: Nombre de usuario de Discord

### Direcciones de Criptomonedas
- **ETH**: Dirección de Ethereum
- **BTC**: Dirección de Bitcoin
- **LTC**: Dirección de Litecoin
- **DOGE**: Dirección de Dogecoin
- Y muchas más criptomonedas soportadas

### Registros Personalizados
Puedes agregar registros de texto personalizados para cualquier propósito:
- **Palabras clave**: Etiquetas o palabras clave
- **Ubicación**: Ubicación geográfica
- **Zona horaria**: Información de zona horaria
- **Idioma**: Idioma preferido
- **Campos personalizados**: Cualquier otra información que quieras almacenar

## Configurar tu Perfil

### Paso 1: Registrar tu Nombre
Primero, necesitas registrar un nombre ENS a través del ENS Manager.

### Paso 2: Agregar Registros
1. Ve a tu nombre en el ENS Manager
2. Haz clic en "Agregar/Editar Registro"
3. Selecciona el tipo de registro que quieres agregar
4. Ingresa la información
5. Guarda el registro

### Paso 3: Establecer Nombre Primario
Si quieres que este sea tu nombre ENS primario:
1. Ve a tu dirección en el ENS Manager
2. Haz clic en "Establecer Nombre Primario"
3. Selecciona tu nombre ENS

## Mostrar Perfiles

### En Wallets
Muchos wallets pueden mostrar perfiles ENS:
- Mostrar avatar y nombre en lugar de dirección
- Mostrar información adicional del perfil
- Enlazar a detalles del perfil

### En Aplicaciones
Las dApps pueden usar perfiles ENS para:
- Identificación de usuario
- Características sociales
- Información de contacto
- Mostrar datos personalizados

## Mejores Prácticas

### Mantener Información Actualizada
- Actualiza regularmente la información de tu perfil
- Elimina registros obsoletos
- Agrega nueva información relevante

### Consideraciones de Privacidad
- Solo agrega información que te sientas cómodo compartiendo públicamente
- Recuerda que los registros ENS son públicos en la blockchain
- Considera usar diferentes nombres para diferentes propósitos

### Completitud del Perfil
- Agrega un avatar para mejor reconocimiento
- Incluye una descripción para ayudar a otros a entender quién eres
- Agrega enlaces relevantes de redes sociales
- Incluye tus direcciones principales de criptomonedas
