# Resolución Inversa

## Original (English)

# Reverse Resolution

Reverse resolution is the process of finding the ENS name associated with a given Ethereum address. This is the opposite of normal resolution, where you find the address associated with an ENS name.

## How Reverse Resolution Works

### Step 1: Reverse Lookup
To find the ENS name for an address, you need to:
1. Take the Ethereum address (e.g., `0x1234...`)
2. Reverse it and append `.addr.reverse`
3. Look up this special ENS name in the registry

### Step 2: Get the Name
The reverse record contains the canonical ENS name for that address.

## Setting Up Reverse Resolution

### For Your Own Address
1. Go to the ENS Manager
2. Search for your address
3. Click "Set Primary Name"
4. Select the ENS name you want to associate with your address

### For Other Addresses
You can only set reverse resolution for addresses you control. If you own an ENS name, you can set it as the primary name for any address you control.

## Use Cases

### Display Names in Applications
- Wallets can show `alice.eth` instead of `0x1234...`
- DeFi apps can display human-readable names
- Social platforms can show ENS names in profiles

### Identity Verification
- Prove ownership of an ENS name
- Link multiple addresses to one identity
- Create a consistent online identity

## Technical Details

### Reverse Record Format
The reverse record is stored as:
- Name: `{address}.addr.reverse`
- Value: The canonical ENS name

### Example
- Address: `0x1234567890123456789012345678901234567890`
- Reverse name: `0x1234567890123456789012345678901234567890.addr.reverse`
- Value: `alice.eth`

## Traducción (Español)

# Resolución Inversa

La resolución inversa es el proceso de encontrar el nombre ENS asociado con una dirección de Ethereum dada. Esto es lo opuesto a la resolución normal, donde encuentras la dirección asociada con un nombre ENS.

## Cómo Funciona la Resolución Inversa

### Paso 1: Búsqueda Inversa
Para encontrar el nombre ENS de una dirección, necesitas:
1. Tomar la dirección de Ethereum (ej., `0x1234...`)
2. Invertirla y agregar `.addr.reverse`
3. Buscar este nombre ENS especial en el registro

### Paso 2: Obtener el Nombre
El registro inverso contiene el nombre ENS canónico para esa dirección.

## Configurar Resolución Inversa

### Para tu Propia Dirección
1. Ve al ENS Manager
2. Busca tu dirección
3. Haz clic en "Establecer Nombre Primario"
4. Selecciona el nombre ENS que quieres asociar con tu dirección

### Para Otras Direcciones
Solo puedes establecer resolución inversa para direcciones que controlas. Si posees un nombre ENS, puedes establecerlo como el nombre primario para cualquier dirección que controles.

## Casos de Uso

### Mostrar Nombres en Aplicaciones
- Los wallets pueden mostrar `alice.eth` en lugar de `0x1234...`
- Las apps DeFi pueden mostrar nombres legibles por humanos
- Las plataformas sociales pueden mostrar nombres ENS en perfiles

### Verificación de Identidad
- Probar propiedad de un nombre ENS
- Vincular múltiples direcciones a una identidad
- Crear una identidad online consistente

## Detalles Técnicos

### Formato del Registro Inverso
El registro inverso se almacena como:
- Nombre: `{dirección}.addr.reverse`
- Valor: El nombre ENS canónico

### Ejemplo
- Dirección: `0x1234567890123456789012345678901234567890`
- Nombre inverso: `0x1234567890123456789012345678901234567890.addr.reverse`
- Valor: `alice.eth`
