# Registrar un Nombre

## Original (English)

# Register a Name

To register a name, you need to:

1. **Connect your wallet** to the ENS Manager app
2. **Search for your desired name** in the search bar
3. **Check availability** - if the name is available, you'll see a "Register" button
4. **Complete the registration** by following the prompts

## Registration Process

### Step 1: Search for a Name
Enter your desired name in the search bar on the ENS Manager homepage. The system will check if the name is available.

### Step 2: Check Availability
If the name is available, you'll see:
- The name you want to register
- The registration fee (currently 0.01 ETH per year for 5+ character names)
- A "Register" button

### Step 3: Complete Registration
Click "Register" and follow these steps:
1. **Request to register** - This creates a transaction to request the name
2. **Wait for the request** - You need to wait for the request to be confirmed on the blockchain
3. **Complete registration** - After the request is confirmed, you can complete the registration

### Step 4: Set Up Your Name
After registration, you can:
- Set a resolver (where your name points to)
- Add records (like your Ethereum address, other cryptocurrency addresses, etc.)
- Set up reverse resolution

## Important Notes

- **Registration fees**: 5+ character names cost 0.01 ETH per year
- **Shorter names**: 3-4 character names have different pricing and may require bidding
- **Renewal**: You need to renew your name before it expires
- **Ownership**: Once registered, you have full control over the name and can create subdomains

## Traducción (Español)

# Registrar un Nombre

Para registrar un nombre, necesitas:

1. **Conectar tu wallet** a la aplicación ENS Manager
2. **Buscar tu nombre deseado** en la barra de búsqueda
3. **Verificar disponibilidad** - si el nombre está disponible, verás un botón "Registrar"
4. **Completar el registro** siguiendo las indicaciones

## Proceso de Registro

### Paso 1: Buscar un Nombre
Ingresa tu nombre deseado en la barra de búsqueda en la página principal de ENS Manager. El sistema verificará si el nombre está disponible.

### Paso 2: Verificar Disponibilidad
Si el nombre está disponible, verás:
- El nombre que quieres registrar
- La tarifa de registro (actualmente 0.01 ETH por año para nombres de 5+ caracteres)
- Un botón "Registrar"

### Paso 3: Completar el Registro
Haz clic en "Registrar" y sigue estos pasos:
1. **Solicitar registro** - Esto crea una transacción para solicitar el nombre
2. **Esperar la solicitud** - Necesitas esperar a que la solicitud sea confirmada en la blockchain
3. **Completar registro** - Después de que la solicitud sea confirmada, puedes completar el registro

### Paso 4: Configurar tu Nombre
Después del registro, puedes:
- Establecer un resolver (donde apunta tu nombre)
- Agregar registros (como tu dirección de Ethereum, otras direcciones de criptomonedas, etc.)
- Configurar resolución inversa

## Notas Importantes

- **Tarifas de registro**: Los nombres de 5+ caracteres cuestan 0.01 ETH por año
- **Nombres cortos**: Los nombres de 3-4 caracteres tienen precios diferentes y pueden requerir ofertas
- **Renovación**: Necesitas renovar tu nombre antes de que expire
- **Propiedad**: Una vez registrado, tienes control total sobre el nombre y puedes crear subdominios
