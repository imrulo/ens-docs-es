# Tutorial: Registro Completo de un Nombre ENS

## Original (English)

# Complete ENS Registration Tutorial

This tutorial will walk you through the complete process of registering an ENS name from start to finish.

## Prerequisites

- An Ethereum wallet (MetaMask, WalletConnect, etc.)
- Some ETH for gas fees and registration
- Access to the ENS Manager app

## Step-by-Step Registration

### Step 1: Connect Your Wallet
1. Go to [app.ens.domains](https://app.ens.domains)
2. Click "Connect Wallet"
3. Select your wallet provider
4. Approve the connection

### Step 2: Search for Your Name
1. In the search bar, type your desired name
2. Make sure to include `.eth` at the end
3. Click "Search" or press Enter

### Step 3: Check Availability
- If available: You'll see a "Register" button
- If taken: You'll see the current owner's information
- If invalid: You'll see an error message

### Step 4: Start Registration
1. Click "Register" if the name is available
2. Review the registration fee
3. Click "Request to Register"

### Step 5: Confirm Transaction
1. Your wallet will open
2. Review the gas fee
3. Click "Confirm" to send the transaction
4. Wait for confirmation

### Step 6: Complete Registration
1. After the first transaction is confirmed, click "Register"
2. Confirm the second transaction
3. Wait for confirmation
4. Your name is now registered!

### Step 7: Set Up Your Name
1. Go to "My Account" in the ENS Manager
2. Click on your newly registered name
3. Add records (address, avatar, etc.)
4. Set as primary name if desired

## Important Notes

- **Two transactions required**: Registration requires two separate transactions
- **Gas fees**: You'll pay gas fees for both transactions
- **Registration fee**: Annual fee based on name length
- **Renewal**: Remember to renew before expiration

## Troubleshooting

### Common Issues
- **Transaction failed**: Check gas limit and try again
- **Name not available**: Try a different name or variation
- **Wallet connection issues**: Refresh and reconnect

### Getting Help
- Check the ENS documentation
- Join the ENS Discord community
- Ask questions on ENS forums

## Traducción (Español)

# Tutorial: Registro Completo de un Nombre ENS

Este tutorial te guiará a través del proceso completo de registrar un nombre ENS de principio a fin.

## Prerrequisitos

- Un wallet de Ethereum (MetaMask, WalletConnect, etc.)
- Algo de ETH para tarifas de gas y registro
- Acceso a la aplicación ENS Manager

## Registro Paso a Paso

### Paso 1: Conectar tu Wallet
1. Ve a [app.ens.domains](https://app.ens.domains)
2. Haz clic en "Conectar Wallet"
3. Selecciona tu proveedor de wallet
4. Aprueba la conexión

### Paso 2: Buscar tu Nombre
1. En la barra de búsqueda, escribe tu nombre deseado
2. Asegúrate de incluir `.eth` al final
3. Haz clic en "Buscar" o presiona Enter

### Paso 3: Verificar Disponibilidad
- Si está disponible: Verás un botón "Registrar"
- Si está tomado: Verás la información del propietario actual
- Si es inválido: Verás un mensaje de error

### Paso 4: Iniciar Registro
1. Haz clic en "Registrar" si el nombre está disponible
2. Revisa la tarifa de registro
3. Haz clic en "Solicitar Registro"

### Paso 5: Confirmar Transacción
1. Tu wallet se abrirá
2. Revisa la tarifa de gas
3. Haz clic en "Confirmar" para enviar la transacción
4. Espera la confirmación

### Paso 6: Completar Registro
1. Después de que la primera transacción sea confirmada, haz clic en "Registrar"
2. Confirma la segunda transacción
3. Espera la confirmación
4. ¡Tu nombre ya está registrado!

### Paso 7: Configurar tu Nombre
1. Ve a "Mi Cuenta" en el ENS Manager
2. Haz clic en tu nombre recién registrado
3. Agrega registros (dirección, avatar, etc.)
4. Establece como nombre primario si lo deseas

## Notas Importantes

- **Dos transacciones requeridas**: El registro requiere dos transacciones separadas
- **Tarifas de gas**: Pagarás tarifas de gas por ambas transacciones
- **Tarifa de registro**: Tarifa anual basada en la longitud del nombre
- **Renovación**: Recuerda renovar antes del vencimiento

## Solución de Problemas

### Problemas Comunes
- **Transacción fallida**: Verifica el límite de gas e intenta de nuevo
- **Nombre no disponible**: Prueba un nombre diferente o variación
- **Problemas de conexión del wallet**: Actualiza y reconecta

- Revisa la documentación de ENS
