# Tutoriales de ENS

Esta sección contiene tutoriales detallados que te guiarán paso a paso para usar ENS.

## 🎯 Tutoriales Disponibles

### [Tutorial: Registro Completo](./registro-completo)
Tutorial detallado que te guía a través del proceso completo de registro de un nombre ENS desde cero.

### [Tutorial: Configurar Perfil Completo](./configurar-perfil-completo)
Aprende a configurar un perfil ENS completo con todos los registros e información importantes.

## 📚 Antes de Comenzar

Antes de seguir estos tutoriales, te recomendamos leer los [Conceptos Básicos](../conceptos-basicos/) para entender mejor cómo funciona ENS.

## 🛠️ Prerrequisitos

Para seguir estos tutoriales necesitarás:

- Un wallet de Ethereum (MetaMask, WalletConnect, etc.)
- Algo de ETH para tarifas de gas y registro
- Acceso a internet y un navegador web
