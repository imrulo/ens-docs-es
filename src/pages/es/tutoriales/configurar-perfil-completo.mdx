# Tutorial: Configurar un Perfil ENS Completo

## Original (English)

# Complete ENS Profile Setup Tutorial

This tutorial will show you how to set up a comprehensive ENS profile with all the important records and information.

## Prerequisites

- A registered ENS name
- Access to the ENS Manager
- Information you want to include in your profile

## Profile Setup Steps

### Step 1: Access Your Name
1. Go to the ENS Manager
2. Click "My Account"
3. Select your ENS name
4. Click "Add/Edit Record"

### Step 2: Set Your Ethereum Address
1. Click "Add Record"
2. Select "Address" → "ETH"
3. Enter your Ethereum address
4. Click "Save"

### Step 3: Add Your Avatar
1. Click "Add Record"
2. Select "Text" → "Avatar"
3. Enter the URL of your profile picture
4. Click "Save"

### Step 4: Add Description
1. Click "Add Record"
2. Select "Text" → "Description"
3. Write a brief description about yourself
4. Click "Save"

### Step 5: Add Website URL
1. Click "Add Record"
2. Select "Text" → "URL"
3. Enter your website URL
4. Click "Save"

### Step 6: Add Social Media
1. Click "Add Record"
2. Select "Text" → "Twitter"
3. Enter your Twitter handle (without @)
4. Click "Save"
5. Repeat for other social platforms

### Step 7: Add Other Cryptocurrency Addresses
1. Click "Add Record"
2. Select "Address" → "BTC" (or other crypto)
3. Enter your Bitcoin address
4. Click "Save"
5. Repeat for other cryptocurrencies

### Step 8: Set as Primary Name
1. Go to "My Account"
2. Click on your address
3. Click "Set Primary Name"
4. Select your ENS name
5. Confirm the transaction

## Advanced Profile Features

### Custom Records
You can add custom text records for any purpose:
- Keywords
- Location
- Timezone
- Language
- Any other information

### Content Hash
Set a content hash to point your ENS name to:
- IPFS content
- Swarm content
- HTTP URLs

### Subdomains
Create subdomains for different purposes:
- `pay.yourname.eth` for payments
- `mail.yourname.eth` for email
- `nft.yourname.eth` for NFTs

## Best Practices

### Profile Completeness
- Add an avatar for recognition
- Include a clear description
- Add relevant social media links
- Include your primary crypto addresses

### Privacy Considerations
- Only add information you're comfortable sharing
- Remember ENS records are public
- Consider using different names for different purposes

### Regular Updates
- Keep your information current
- Remove outdated records
- Add new relevant information

## Traducción (Español)

# Tutorial: Configurar un Perfil ENS Completo

Este tutorial te mostrará cómo configurar un perfil ENS completo con todos los registros e información importantes.

## Prerrequisitos

- Un nombre ENS registrado
- Acceso al ENS Manager
- Información que quieres incluir en tu perfil

## Pasos de Configuración del Perfil

### Paso 1: Acceder a tu Nombre
1. Ve al ENS Manager
2. Haz clic en "Mi Cuenta"
3. Selecciona tu nombre ENS
4. Haz clic en "Agregar/Editar Registro"

### Paso 2: Establecer tu Dirección de Ethereum
1. Haz clic en "Agregar Registro"
2. Selecciona "Dirección" → "ETH"
3. Ingresa tu dirección de Ethereum
4. Haz clic en "Guardar"

### Paso 3: Agregar tu Avatar
1. Haz clic en "Agregar Registro"
2. Selecciona "Texto" → "Avatar"
3. Ingresa la URL de tu foto de perfil
4. Haz clic en "Guardar"

### Paso 4: Agregar Descripción
1. Haz clic en "Agregar Registro"
2. Selecciona "Texto" → "Descripción"
3. Escribe una breve descripción sobre ti
4. Haz clic en "Guardar"

### Paso 5: Agregar URL del Sitio Web
1. Haz clic en "Agregar Registro"
2. Selecciona "Texto" → "URL"
3. Ingresa la URL de tu sitio web
4. Haz clic en "Guardar"

### Paso 6: Agregar Redes Sociales
1. Haz clic en "Agregar Registro"
2. Selecciona "Texto" → "Twitter"
3. Ingresa tu handle de Twitter (sin @)
4. Haz clic en "Guardar"
5. Repite para otras plataformas sociales

### Paso 7: Agregar Otras Direcciones de Criptomonedas
1. Haz clic en "Agregar Registro"
2. Selecciona "Dirección" → "BTC" (u otra cripto)
3. Ingresa tu dirección de Bitcoin
4. Haz clic en "Guardar"
5. Repite para otras criptomonedas

### Paso 8: Establecer como Nombre Primario
1. Ve a "Mi Cuenta"
2. Haz clic en tu dirección
3. Haz clic en "Establecer Nombre Primario"
4. Selecciona tu nombre ENS
5. Confirma la transacción

## Características Avanzadas del Perfil

### Registros Personalizados
Puedes agregar registros de texto personalizados para cualquier propósito:
- Palabras clave
- Ubicación
- Zona horaria
- Idioma
- Cualquier otra información

### Hash de Contenido
Establece un hash de contenido para que tu nombre ENS apunte a:
- Contenido IPFS
- Contenido Swarm
- URLs HTTP

### Subdominios
Crea subdominios para diferentes propósitos:
- `pay.tunombre.eth` para pagos
- `mail.tunombre.eth` para email
- `nft.tunombre.eth` para NFTs

## Mejores Prácticas

### Completitud del Perfil
- Agrega un avatar para reconocimiento
- Incluye una descripción clara
- Agrega enlaces relevantes de redes sociales
- Incluye tus direcciones principales de criptomonedas

### Consideraciones de Privacidad
- Solo agrega información que te sientas cómodo compartiendo
- Recuerda que los registros ENS son públicos
- Considera usar diferentes nombres para diferentes propósitos

### Actualizaciones Regulares
- Mantén tu información actualizada
- Elimina registros obsoletos
- Agrega nueva información relevante
