# Guías de Usuario ENS

Esta sección contiene guías prácticas para gestionar y mantener tus nombres ENS una vez que ya los tienes registrados.

## 📖 Guías Disponibles

### [Renovar un Nombre](./renovar-nombre)
Guía completa sobre cómo renovar tu nombre ENS antes de que expire.

### [Transferir un Nombre](./transferir-nombre)
Cómo transferir la propiedad de un nombre ENS a otra dirección de manera segura.

## 🎯 Cuándo Usar Estas Guías

Estas guías son útiles cuando:

- Tu nombre ENS está próximo a vencer
- Quieres transferir un nombre a otra persona
- Necesitas gestionar múltiples nombres ENS
- Quieres entender las mejores prácticas de gestión

## 📚 Conocimientos Previos

Antes de usar estas guías, asegúrate de tener:

- Un nombre ENS registrado
- Conocimiento básico de ENS (revisa [Conceptos Básicos](../conceptos-basicos/))
- Acceso al ENS Manager
- Un wallet conectado
