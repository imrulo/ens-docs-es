# Deployments

:::note
This page contains information that is only relevant to developers who would
like to interact with the contract manually. Most libraries will handle this
for you.
:::

ENS is multichain (read more [here](/es/web/multichain)) and can be used in any application.
In addition to being able to query many address formats and record types, data can be stored [practically anywhere](/learn/ccip-read).
However, resolution needs to start somewhere, so the entrypoint for resolution is Ethereum Mainnet, alongside the most popular testnets.

# Despliegues

:::note
Esta página contiene información que solo es relevante para desarrolladores que querrían
interactuar con el contrato manualmente. La mayoría de librerías manejarán esto
por ti.
:::

ENS es multichain (lee más [aquí](/es/web/multichain)) y puede ser usado en cualquier aplicación.
Además de poder consultar muchos formatos de dirección y tipos de registro, los datos pueden almacenarse [prácticamente en cualquier lugar](/es/learn/ccip-read).
Sin embargo, la resolución necesita comenzar en algún lugar, por lo que el punto de entrada para la resolución es Ethereum Mainnet, junto con las testnets más populares.
