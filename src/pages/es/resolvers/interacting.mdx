# Interactuar con un Resolver [Establecer Direcciones, Registros de Texto, y más]

Algunas aplicaciones pueden querer permitir a los usuarios editar, actualizar o modificar su nombre y su comportamiento a un nivel más avanzado.
Esto es posible interactuando directamente con el contrato resolver de un nombre.

## Verificar Soporte de Interfaz

Antes de empezar a enviar transacciones a los resolvers de los usuarios, deberías verificar si soportan la interfaz que quieres usar. Esto se hace llamando a la función `supportsInterface` (ver [EIP-165](https://eips.ethereum.org/EIPS/eip-165)) en el contrato resolver.

```solidity
function supportsInterface(bytes4 interfaceID) external pure returns (bool)
```

Para asegurar que los resolvers con los que interactuamos son compatibles con estándares específicos puedes llamar a la función anterior en contratos con un interfaceID y luego verificar el booleano que devuelve.

Los IDs de interfaz se calculan según el ABI de Solidity y se almacenan en un valor de cuatro bytes.

## Actualizar el Registro de un Usuario

Si quieres ayudar a un usuario a establecer su avatar, especificar un esquema de colores preferido, o establecer cualquier otro registro en su nombre ENS puedes hacerlo en casos específicos.

Primero necesitamos <b>verificar si el resolver del usuario soporta la interfaz</b> que queremos usar (ver [setText](/es/resolvers/interfaces#0x10f13a8c)).
Después puedes llamar a la función `setText()` en el contrato resolver del usuario.

:::code-group

```solidity [Solidity]
interface Resolver {
    function setText(bytes32 node, string calldata key, string calldata value) external;
}
```

```typescript [ENSjs]
// https://github.com/ensdomains/ensjs/blob/main/docs/wallet/function.setRecords.md
import { addEnsContracts } from '@ensdomains/ensjs'
import { setRecords } from '@ensdomains/ensjs/wallet'
import { createWalletClient, custom } from 'viem'
import { mainnet } from 'viem/chains'

const wallet = createWalletClient({
  chain: addEnsContracts(mainnet),
  transport: custom(window.ethereum),
})
const hash = await setRecords(wallet, {
  name: 'ens.eth',
  coins: [
    {
      coin: 'ETH',
      value: '0xFe89cc7aBB2C4183683ab71653C4cdc9B02D44b7',
    },
  ],
  texts: [{ key: 'foo', value: 'bar' }],
  resolverAddress: '0x4976fb03C32e5B8cfe2b6cCB31c09Ba78EBaBa41',
})
// 0x...
```

:::

Por favor, haz claro al usuario qué estás haciendo y por qué. Si es posible, también muestra el registro que estás estableciendo al usuario antes de hacerlo.

## Actualizar el Resolver de un Usuario

Sobrescribir el resolver de un usuario implica sobrescribir el comportamiento de su nombre ENS.

Para sobrescribir el resolver de un usuario necesitas llamar a la función `setResolver` en el contrato `ENSRegistry`.

:::code-group

```solidity [Solidity]
interface ENS {
    function setResolver(bytes32 node, address resolver) external;
}
```

```typescript [ENSjs]
// https://github.com/ensdomains/ensjs/blob/main/docs/wallet/function.setResolver.md
import { addEnsContracts } from '@ensdomains/ensjs'
import { setResolver } from '@ensdomains/ensjs/wallet'
import { createWalletClient, custom } from 'viem'
import { mainnet } from 'viem/chains'

const wallet = createWalletClient({
  chain: addEnsContracts(mainnet),
  transport: custom(window.ethereum),
})
const hash = await setResolver(wallet, {
  name: 'ens.eth',
  contract: 'registry',
  resolverAddress: '0x4976fb03C32e5B8cfe2b6cCB31c09Ba78EBaBa41',
})
// 0x...
```

:::

Por favor, no cambies el resolver de un usuario sin su permiso. Sobrescribir el resolver es una acción destructiva y sobrescribirá cualquier lógica de resolución existente.
