# Documentación ENS en Español

Este repositorio contiene la traducción al español de la documentación oficial de ENS (Ethereum Name Service), enfocada en usuarios finales y siguiendo las mejores prácticas de traducción técnica profesional.

## Estructura del Proyecto

La documentación traducida se encuentra en el directorio `src/pages/es/` y mantiene la misma jerarquía que la documentación oficial:

```text
src/pages/es/
├── index.mdx                 # Página principal
├── faq.mdx                   # Preguntas Frecuentes
├── terminology.mdx           # Terminología técnica
├── learn/
│   └── protocol.mdx          # ¿Qué es ENS?
├── web/
│   └── quickstart.mdx        # Guía rápida para desarrolladores
├── registry/
│   └── eth.mdx              # Registrador ETH
└── resolution/
    └── index.mdx            # Resolución de nombres
```

## Secciones Traducidas

### Para Usuarios Finales

- **Página Principal**: Introducción general a ENS
- **FAQ**: Preguntas frecuentes sobre el uso de ENS
- **Terminología**: Glosario de términos técnicos
- **Protocolo ENS**: Explicación del servicio de nombres

### Para Desarrolladores

- **Guía Rápida**: Implementación básica en dApps
- **Registro ETH**: Detalles técnicos del registrador
- **Resolución**: Cómo funciona la resolución de nombres

## Principios de Traducción

1. **Consistencia**: Mantenimiento de terminología técnica consistente
2. **Precisión**: Traducción precisa de conceptos técnicos de ENS/Ethereum
3. **Claridad**: Lenguaje claro y profesional para usuarios finales
4. **Jerarquía**: Preservación de la estructura y orden original

## Terminología Clave

- **ENS**: Servicio de Nombres de Ethereum
- **Resolver**: Resolver (mantenido en inglés por ser término técnico)
- **Registro**: Registry (mantenido en inglés por ser término técnico)
- **Registrador**: Registrar
- **Subnombre/Subdominio**: Subname/Subdomain
- **TLD**: Dominio de Primer Nivel
- **Namehash**: Namehash (mantenido en inglés por ser término técnico)
